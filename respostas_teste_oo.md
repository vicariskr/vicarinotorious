# Respostas do Teste de Orientação a Objetos

## Pergunta 1: Como os objetos interagem uns com os outros?

**Resposta: Opção E - Os objetos interagem e se comunicam através de mensagens.**

**Justificativa:** Em programação orientada a objetos, os objetos se comunicam através do envio de mensagens. Quando um objeto chama um método de outro objeto, está enviando uma mensagem. Este é o conceito fundamental de comunicação entre objetos em OOP.

---

## Pergunta 2: Qual das frases abaixo define melhor o significado de classe?

**Resposta: Opção E - Agrupamento de objetos que têm uma ou mais características em comum.**

**Justificativa:** Uma classe é um molde ou template que define as características (atributos) e comportamentos (métodos) comuns que os objetos instanciados a partir dela terão. É uma abstração que agrupa objetos com características similares.

---

## Pergunta 3: "Toda classe é instância de um objeto." - Verdadeiro ou Falso?

**Resposta: Falso**

**Justificativa:** A afirmação está invertida. Na verdade, todo **objeto** é uma instância de uma **classe**, não o contrário. A classe é a definição/template, e o objeto é a instância concreta criada a partir dessa classe.

---

## Pergunta 4: A notação OOA&D consiste em três partes:

**Resposta: Opção E - Processo, notação e design.**

**Justificativa:** OOA&D (Object-oriented Analysis and Design) consiste em:
- **Processo**: A metodologia e os passos para análise e design orientado a objetos
- **Notação**: A linguagem visual comum (como UML - Unified Modeling Language) para representar o sistema
- **Design**: O resultado do processo de design, criando a estrutura do sistema

---
